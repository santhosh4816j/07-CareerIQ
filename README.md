# CareerIQ — Project 07/20

AI-style Resume & Job Matching.

## Start
Node.js 20.10+ recommended. Run `npm.cmd start` in PowerShell, then visit http://localhost:4107. No dependencies or API keys required.

## Test
`npm.cmd test`

## Features
Domain-specific data entry, editable records, delete, full-text search, CSV export, persistent JSON store, activity log, analytics and responsive dashboard.

## REST API
GET /health; GET /api/config; GET/POST /api/records; PATCH/DELETE /api/records/:id; GET /api/stats; GET /api/export.

## Scope
This is a local full-stack foundation, not a production-ready system. Simulated/rule-based insights are clearly identified; no real external services or cloud integrations. Do not expose to public networks without adding authentication, authorization, and security controls.
